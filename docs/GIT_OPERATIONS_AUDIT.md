# Git operation review — 2026-10-23

Scope: repository sidebar/header actions, local changes recovery, workspace lifecycle and GitHub/task integration. Native Git/process authority remains in Rust; React uses typed wrappers. No arbitrary-shell API, automatic force retry, remote checkout, merge or push was added.

Codex analyses intentionally use CLI authentication with user CLI configuration ignored, avoiding user hooks/plugins/MCP in the metadata job. Existing interactive workspace agents and terminals retain their own configuration. A compatible installed CLI is required; failures offer an explicitly selected rule preview. Squash/rebase integration, branch business ownership and collaborator intent cannot be proven from the supplied metadata, so uncertain branches are kept. Review recommendations are advisory.

External Git clients are outside application lifecycle locks. OID transactions, push leases and immediate ownership/state checks reduce races; Git does not provide one transaction spanning worktree directory removal and remote ref deletion. Partial outcomes are reported and never described as atomic rollback.

Validation results are recorded in the implementation plan. Cross-platform runner checklists require real corresponding hosts; running the Windows runner is not evidence of Linux/macOS interactive acceptance.
